Section 0

Before you start

Four changes to the running system. Three of them alter behaviour people already rely on — read what changed below before you decide whether something is a bug.

Item 1 · Leave Balance Gate
Behaviour changeEmployees can no longer apply for more leave than they hold. On by default.
Item 2 · Super Admin masking
Display changeSuper Admin actions read as “System Admin” to everyone else.
Item 3 · Bulk payslip delete
New capabilityClear a wrong payroll run — a month, a department, or one employee.
Item 4 · Combined Leave
New capabilityFund one request from two leave types: 0.5 Casual + 0.5 Sick = one day.

Suite 1 · 10 cases

Leave Balance Gate

An employee can no longer apply for more leave than they actually have. The form stops it, and so does the server if the form is bypassed.

What changed. Previously an employee could apply for any number of days and HR decided the paid / unpaid split at approval. With the gate on, a request that exceeds the balance never reaches HR. It fires on any shortfall — 2 days in hand and a 3-day request is refused, not just a zero balance.

Suite 3 · 9 cases

Super Admin masking

Anything the Super Admin does reads as System Admin to everyone else. The stored record still holds the real account, so a database audit is unaffected.

Set-up. Sign in as the Super Admin in one browser and do something that leaves a trail — edit a customer, create a lead, change a setting. Then open the second browser as a plain Admin and compare what each of you sees on the dashboard.
Suite 4 · 12 cases

Bulk payslip delete

For the case you described: a run generated by mistake, or on a wrong calculation, cleared so the month can be generated again.

Use a test month. Generate payroll for a month you do not mind losing before you start deleting. Do not practise on a month that has been paid out.
Suite 5 · 6 cases

Re-running a cleared month

The part that matters most: deleting a payslip must put back everything it had consumed, or money silently disappears from the next run.

Why this matters. Generating a payslip marks the penalties it deducted as deducted and the incentives it paid as applied. The generator only ever picks up penalties and adjustments that have not been used yet. If deleting a payslip left those flags set, the penalty would be written off and the incentive would never be paid — and nobody would notice until an employee complained.
Suite 6 · 12 cases

Combined Leave

One request funded from more than one leave type, so leftover half-days in different buckets still add up to a day off.

The headline case. An employee with 0.5 Casual and 0.5 Sick left has no full day anywhere — and with the Balance Gate on, neither type alone will let them apply. Combining the two halves gives them their day, and deducts 0.5 from each.
Suite 7 · 6 cases
