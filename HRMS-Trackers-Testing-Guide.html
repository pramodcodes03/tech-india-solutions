Section 0

Before you start

This plan covers the three operational registers added to the HRMS: Break Sheet, Diesel and Daily Visitor. You do not need any prior knowledge of the ERP — every case below tells you exactly where to click, what to type and what should happen.

How to use this page

  1. Work through the sections in order — later sections assume the records created in earlier ones exist.
  2. For each case press P (pass), F (fail) or B (blocked). Your marks are saved in this browser, so you can close the page and come back to it.
  3. When something fails, note it against the case ID using the bug template in Section 13.
  4. At the end press Copy summary in the header and paste the result into the QA thread.
Prepare this first. You need at least three active employees in HR → Employees (each with an Employee ID), and one PDF or JPG under 5 MB on your machine to use as a fuel slip. Nothing else needs setting up — the dropdown values ship pre-filled.

  1. Log in to the admin panel. The sidebar is the dark column down the left of every screen.
  2. Scroll the sidebar to the HUMAN RESOURCES heading. It sits below Purchase and above Asset Management.
  3. Click Trackers. The group expands to six links.
  4. All Trackers is the hub — three summary cards, one per register. Start there.
Can't see Trackers? The whole group is permission-gated. If your login has none of the tracker permissions the group is hidden entirely — that is correct behaviour, and it is what Section 11 tests. Log in as Admin or HR Manager to see it.

Shortcut

The sidebar has a Search menu… box at the top. Typing track highlights the group without scrolling.

Suite 1 · 6 cases

Access & navigation

Prove every screen opens from the sidebar and the hub reflects what is in the registers.

Suite 2 · 12 cases

Break Sheet Tracker

An employee break register. The headline behaviour to prove: Total Timing is never typed — the system works it out from Out Time and In Time, live on the form and again on save.

Suite 3 · 14 cases

Diesel Tracker

A fuel register where every entry can carry its bill or slip as proof, measured against a monthly budget.

Suite 4 · 11 cases

Daily Visitor Tracker

Office visitors and interview candidates, with the source they came from and what came of the visit.

Suite 5 · 6 cases

Tracker Settings

One screen maintains all three dynamic dropdowns: Break Type, Visitor Source and Purpose of Visit.

Suite 6 · 10 cases

Filters, search & sorting

The same filter bar sits on all three registers: five period modes, a search box, register-specific dropdowns, and sortable column headers.

Suite 7 · 8 cases

Excel import

Each register imports historical data through the shared import pipeline: upload → validate → preview → confirm. Nothing is written until you confirm.

Suite 8 · 7 cases

Excel & PDF export

Both buttons export what is currently on screen — the same period, search, filters and sort order.

Suite 9 · 8 cases

Roles & permissions

Each register is a separate module row in Management → Roles & Permissions, so one register can be granted without the others.

Set-up for this suite. Go to Management›Roles & Permissions›Create Role and make a role called Front Desk. Tick only visitor_tracker → view, create, edit. Save it, then create a test admin user with that role and log in as them in a private window (so you keep your Admin session open in the other).
